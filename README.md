# Todo App

A live-coding example used throughout the Android Development lecture at DHBW Heidenheim, extended incrementally as new concepts are introduced.

## Concepts covered
- MVVM architecture with ViewModel and StateFlow
- Multi-screen navigation with Jetpack Compose Navigation 3
- Implemented several Composables including LazyColumn with swipe2delete
- Bottom navigation bar with filter states
- Dependency injection with Hilt
- Local persistence with Room
- REST API integration with loading and error handling
- CRUD operations for filtering (all / open / done)

## Tech stack
Kotlin, Jetpack Compose, Hilt, Room, Retrofit
